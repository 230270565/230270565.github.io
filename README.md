## Reflection: Published on GitHub Pages
The assignment required us to publish our work publicly using GitHub Pages, which was a tool I had not used before.
I needed to deploy my GitHub profile and CV to a live GitHub Pages link.
The initial setup was confusing as I was not familiar with how GitHub Pages works. I worked through it without a step-by-step guide at first, ran into a few issues, and eventually got it live. I then went back and redid the process once I understood it better, which helped solidify how it actually works.
Going through it twice made a noticeable difference. The second time around it was straightforward and I understood what each step was doing. I now have a working published link and a clear understanding of how static site hosting through GitHub Pages works, which is a useful skill for showcasing projects in future.
