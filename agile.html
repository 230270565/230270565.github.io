Project overview

Project
GoldenWay, a mobile-first ticketing and transit app for Golden Arrow commuters
Team
Group 26, five members, each owning one user role
My role
Agent: the support staff who answer commuters in live chat and manage support tickets
Stack
React, JavaScript, Supabase, SQL, deployed on Vercel
Method
Weekly sprints, Kanban board on Trello, stand-ups and weekly retrospectives
Board
Team Trello board

1. Agile Team Charter

The charter is the team's agreement on why we were building GoldenWay, how we would work, and who owned which part.

Evidence (10%)

Product goal: a deployed, mobile-first app where commuters buy and use Gold Card trips, and each kind of Golden Arrow staff member has their own tools to support that.

MemberResponsibility
Joshua AdamsTeam lead; Commuter and Clerk roles; reviews and merges
Matthew BarronAdmin role
Aidan BarendsDriver role
Raul Everts (me)Agent role: support chat and ticket queue
Joshua BirdInspector role (joined August 2026)

Values

  • Ubuntu
  • Ownership
  • Technical foresight
  • Resilience
  • Ethical data handling

Working agreements

  • Everyone works on their own branch; nothing is pushed straight to main.
  • Changes go in through pull requests that the lead reviews.
  • Check with the owner before editing a file they're working on.
  • Planning on Tuesdays, stand-ups on class days, a retrospective every week.
  • Database changes go in as migrations, applied before testing.

2. User Stories and Tasks

User stories describe a feature from the user's point of view. Each one was broken down into tasks on a Trello card.

Evidence (10%)

The stories on my side of the app:

User storyPriority
As an agent, I want to answer commuters' support queries in live chat, so their problems are resolved quickly.Must have
As an agent, I want to claim, resolve and escalate support tickets from a queue, so every query has an owner.Should have
As an agent, I want to set my online status, so commuters know when an agent is available to help.Could have
As a commuter, I want to report a problem with my trip through support chat, so it gets resolved.Could have
